# ☁️ AWS Certified Cloud Practitioner (CLF-C02) Exam Reviewer 2026

An offline-capable, interactive web-based exam practice application designed to help prepare for the **AWS Certified Cloud Practitioner (CLF-C02)** certification exam. 

---

## 🌟 Features

* **260 Unique Hand-Crafted Questions:** Divided equally into 65 scenario-based questions per domain.
* **4 AWS CLF-C02 Exam Domains Covered:**
  * 🎯 **Domain 1:** Cloud Concepts (65 Questions)
  * 🛡️ **Domain 2:** Security and Compliance (65 Questions)
  * ⚙️ **Domain 3:** Cloud Technology and Services (65 Questions)
  * 💰 **Domain 4:** Billing, Pricing, and Support (65 Questions)
* **Custom Practice Modes:**
  * Filter by specific domain or take a full 260-question mock exam.
  * Customizable question volume per session (e.g., 10, 25, 65 questions).
  * Built-in timed mode with customizable time limits.
* **Instant Explanations & Review:**
  * Real-time answer validation and detailed explanations for every option.
  * Comprehensive end-of-exam performance breakdown and score summary.
* **Zero Infrastructure Overhead:**
  * Fully client-side app hosted via GitHub Pages. No backend database required.
